# MIPs

This directory contains Murm Improvement Proposals.

Each MIP should be small enough to implement independently and precise enough to
produce compatible implementations in TypeScript, Go, Rust, or other languages.

## Current Drafts

| MIP | Title | Status |
| --- | --- | --- |
| [MIP-01](MIP-01.md) | `event format` | `draft` |
| [MIP-02](MIP-02.md) | `signatures` | `draft` |

## Suggested Structure

Each MIP should generally include:

- Title
- Status
- Abstract
- Motivation
- Specification
- Examples
- Validation
- Security Considerations
